# 🚀 Redux Toolkit Counter App

A modern, responsive counter application built to master global state management using **React**, **Redux Toolkit**, and **Tailwind CSS**.

## ✨ Features

- **Increment & Decrement:** Basic counter controls with built-in state protection (prevents the counter from dropping below 0).
- **Custom Amount Input:** Allows users to input a custom number and dynamically increase the counter using Redux action payloads.
- **Dynamic UI States:** Disables the decrement button and applies visual feedback when the counter hits zero, preventing layout flickers.
- **Clean Dark-Themed UI:** Styled with Tailwind CSS for a sleek, modern, and accessible look.
